# Repositório da turma

Este repositório é da turma da Formação Full-Stack. Ele existe para você treinar a contribuir no projeto de outra pessoa: fork, branch, pull request e resposta ao review.

Aqui ninguém quebra nada: cada pessoa mexe só nos próprios arquivos.

## O que tem aqui

- `alunos/`: um cartão de apresentação por pessoa da turma.
- `dicas/`: dicas de Git e terminal, uma por arquivo.

## Como contribuir

1. Escolha uma issue com a etiqueta `good first issue` e leia os critérios de aceite.
2. Faça o fork deste repositório (botão **Fork**, lá em cima).
3. Clone o **seu** fork e crie uma branch para a tarefa.
4. Faça a mudança, commit e push para o seu fork.
5. Abra o pull request para este repositório, preenchendo o modelo de descrição.
6. Recebeu review? Responda com um **commit novo na mesma branch**. O PR se atualiza sozinho: não abra outro.

Os nomes dos arquivos usam o seu usuário do GitHub, em minúsculas: `alunos/seu-usuario.md`. Os arquivos `exemplo.md` mostram o formato.
